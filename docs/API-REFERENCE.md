# API Reference - Overview

Base URL: `<origin>/api` (`API_PREFIX`). About **635 route registrations** in 44 router files (counted statically; 571 listed individually in the six reference files plus 64 generated by two loops, documented explicitly below). Live OpenAPI is served at `/api/docs` (JSON at `/api/docs.json`) when `API_DOCS_ENABLED` is true (default in dev, off in production). The hand-written spec (`config/swagger.js` + nine `swagger.*.js` module files) is **not** guaranteed to include every route - the router source is authoritative; this reference was generated from it.

## Response and error conventions

```json
{ "success": true, "message": "OK", "data": { } }
{ "error": { "message": "Validation failed", "code": "VALIDATION_ERROR", "details": { "field": ["message"] } } }
```

* `201` uses the same envelope with message "Created" (`apiResponse.created`). `POST /auth/refresh` returns the bare `{ "data": { accessToken, refreshToken } }`.
* 401 `UNAUTHENTICATED` / `TOKEN_INVALID`; 403 `FORBIDDEN` / `WRONG_PORTAL` / `ONBOARDING_INCOMPLETE` (approval gates) / `DOCTOR_NOT_VERIFIED`; 404 `NOT_FOUND`; 409 conflict family (`EMAIL_IN_USE`, `SLOT_TAKEN`, `DUPLICATE_BOOKING`, ...); 422 `VALIDATION_ERROR`; 429 `RATE_LIMITED`; 503 for unconfigured providers (`SMS_UNAVAILABLE`, `VIDEO_NOT_CONFIGURED`, payments). Full code list in [MIDDLEWARE-VALIDATION-AND-ERRORS.md](MIDDLEWARE-VALIDATION-AND-ERRORS.md).
* Unmatched routes: `404 NOT_FOUND` "Route not found: <METHOD> <url>".
* Stored files in any response are rewritten by the JSON replacer: private files become `<PUBLIC_URL>/api/files/<signed token>/<name>`.
* Dates: ISO strings. Day-level business logic (dashboards, reminders) uses IST (+05:30).

| Endpoint | Parameters |

| `GET /api/doctors` | `search, specialtySlug, subSpecialtySlug, symptomSlug, stateCode, city, hospital, gender, language, minExperience, maxFee, minRating, videoConsult, verified, available, sort (relevance, rating, experience, fee, nearest), lat, lng, page, pageSize (default 9, max 50), includeIds, excludeIds` - executed in SQL (`doctorSearch.service`); `nearest` requires lat+lng |

| Medicine browse / provider lists | `validateQuery` schemas in `medicineStore.validator.js` (filters include `providerId`, `minDiscount`, `lat`, `lng`, `radiusKm`) |

## Key request shape: create a booking

`POST /api/patient/bookings` (patient): `{ doctorId, mode: "video"|"clinic", clinicId (required for clinic, forbidden for video), date (ISO day), paymentMode: "online"|"offline", offlineMethod: "cash"|"upi_qr" (default cash; upi_qr requires offline), referralId?, acquisition?: { source, otherText?, referralDetails?, capturedVia?, utm? } }`. The client never sends an amount; the server computes the fee. Response: `{ booking, razorpayOrder }` (order is null for offline / dev-bypass).
